# Thorax & GI lab identification questions

"What is this?" questions made from every label on the lab pictures: all labels covered, the asked one marked ?, five look-alike choices. One page per picture type (cadaver, plastination, Visible Body, X-ray & CT, cross-sections, bones), split by region. Pictures come from ../img. Built by `Fall Courses/_labocc/scripts/idq_build.py`, `idq_pages.py`, `idq_deploy.py`.

Live: https://yoelplutchok.github.io/thorax-gi-lab-pictures/questions/
