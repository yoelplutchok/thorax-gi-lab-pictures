# Thorax & GI lab pictures

Study page for the Touro Thorax + Abdomen lab practical: 258 labelled pictures (cadaver, plastination, Visible Body, X-ray/CT, cross-sections) grouped by region. Every label starts covered; click a box to reveal it. Each picture has Hide/Show labels buttons, the top bar has Reveal all / Hide all and a "top N high-yield" filter.

Built from the Canvas "Cardio/Pulmonary and GI Lab Documents" page (Nov 2 2026), the NetAnatomy images listed in its image guide, and the 2020/2021 Middletown TA mock practicals. Pipeline: `Fall Courses/_labocc/`.
